Ringkasan aplikasi & alur kerja harian

Overview
Gambaran umum fitur utama POS PRO Offline dan alur kerja harian yang disarankan untuk kasir dan pemilik usaha.

Apa itu POS PRO Offline?

POS PRO Offline adalah aplikasi kasir yang berjalan lokal di komputer/laptop Anda, dirancang untuk:

  • Mengelola penjualan kasir harian (menu pos.html).
  • Mengelola stok, mutasi barang, dan penyesuaian (menu mutasi-barang.html dan halaman admin).
  • Mencatat piutang / hutang pelanggan beserta cetak struk khusus.
  • Menyajikan laporan penjualan & kas (menu revenue.html dan laporan lainnya).
  • Sinkronisasi data (bila diaktifkan) melalui sync.html.

Alur kerja harian yang direkomendasikan

  1. Buka aplikasi & login
    Jalankan aplikasi, login sebagai kasir atau admin sesuai kebutuhan.
  2. Pastikan kas awal & printer siap
    Siapkan uang kembalian di laci, pastikan printer struk menyala dan kertas cukup.
  3. Lakukan transaksi kasir (POS)
    Input barang, pilih pelanggan bila perlu, dan simpan transaksi. Struk akan otomatis tercetak.
  4. Catat mutasi khusus (bila ada)
    Untuk retur, koreksi stok, atau pindah gudang, gunakan menu mutasi/stok.
  5. Cek laporan penjualan
    Di akhir shift/hari, cek menu laporan penjualan & kas, cocokkan dengan uang fisik.
  6. Lakukan backup data
    Minimal 1x per hari, simpan backup ke flashdisk atau cloud storage.
✅

Ikuti alur di atas setiap hari untuk meminimalkan selisih kas, kehilangan data, dan stok yang tidak akurat.

Instalasi & setup awal aplikasi

Setup awal
Langkah demi langkah mulai dari persiapan komputer, instalasi, hingga berhasil login pertama kali ke aplikasi.

1. Spesifikasi minimum perangkat

  • OS: Windows 10 / 11 (64-bit) disarankan.
  • RAM: minimal 4 GB (8 GB lebih nyaman).
  • Prosesor: setara Intel i3 / AMD sekelasnya.
  • Ruang kosong disarankan: 5–10 GB.
  • Printer struk USB/LAN (58 mm atau 80 mm) bila ingin cetak struk.
⚠️

Hindari instal di komputer yang sering dimatikan paksa, agar data database tidak mudah rusak.

2. Instalasi aplikasi

  1. Pastikan file installer/aplikasi sudah lengkap.
  2. Klik kanan → Run as administrator bila diminta izin.
  3. Ikuti wizard instalasi sampai selesai (Next → Next → Finish).
  4. Setelah selesai, pastikan ada shortcut aplikasi di Desktop atau Start Menu.

3. Login pertama kali

Secara default, biasanya tersedia akun admin awal (contoh):

Role User Password Keterangan
Admin / Owner admin •••••• Gunakan akun ini hanya untuk pemilik.
⛔

Setelah berhasil login, segera ganti password default admin, dan jangan sebarkan ke kasir.

4. Urutan setup awal yang direkomendasikan

  1. Login sebagai admin/pemilik.
  2. Buka menu Pengaturan Toko / Company Profile dan isi:
    • Nama toko, alamat, no. telp, NPWP (bila ada).
    • Logo (jika didukung, akan tampil di struk/faktur).
  3. Isi master kategori, satuan, supplier.
  4. Input master barang beserta harga jual dan stok awal.
  5. Atur user kasir dan batasi hak aksesnya.
  6. Hubungkan dan uji printer struk.
  7. Lakukan 1–2 transaksi percobaan dan cek laporan.

Pengaturan master data toko

Master data
Master data yang rapi akan membuat transaksi kasir dan laporan menjadi lebih akurat dan mudah dianalisa.

1. Data toko / profil perusahaan

Buka menu Pengaturan → Data Toko:

  • Isi nama toko sesuai yang ingin tampil di struk.
  • Lengkapi alamat, nomor telepon, dan keterangan pajak.
  • Jika mendukung logo, upload logo resolusi kecil (sekitar 200–300 px lebar).

2. Kategori & satuan barang

Sebelum input barang, buat kategori dan satuan:

  • Contoh kategori: Minuman, Makanan, Snack, Obat, dll.
  • Contoh satuan: Pcs, Dus, Botol, Pack.
  • Gunakan penamaan singkat dan konsisten agar kasir mudah mencari.

3. Supplier dan pelanggan (opsional tapi direkomendasikan)

Untuk memudahkan tracking hutang/piutang dan laporan per relasi:

  • Tambahkan supplier utama (distributor besar tempat Anda belanja stok).
  • Tambahkan pelanggan langganan yang sering berhutang / pembayaran tempo.

4. Input master barang

  1. Buka menu Master Barang / Produk pada halaman admin.
  2. Untuk setiap barang, isi minimal:
    • Kode barang (boleh gunakan kode sendiri / barcode).
    • Nama barang yang mudah dibaca kasir.
    • Kategori & satuan.
    • Harga beli dan harga jual.
    • Stok awal (bila Anda mulai menggunakan di tengah jalan).
  3. Simpan dan cek di menu POS; pastikan bisa dicari dengan cepat.
💡

Jika memakai barcode scanner, pastikan nilai kode barang diisi sesuai dengan barcode fisik, agar kasir cukup scan tanpa ketik manual.

Pengaturan printer & struk

Printer
Menghubungkan aplikasi dengan printer struk agar setiap transaksi penjualan otomatis mencetak bukti bayar profesional.

1. Hubungkan printer ke Windows

  1. Colokkan kabel USB / pastikan koneksi LAN printer sudah benar.
  2. Buka Control Panel → Devices and Printers.
  3. Pastikan printer struk muncul dan bisa melakukan Print Test Page.

2. Pilih printer di aplikasi

Di menu pengaturan printer pada halaman admin (admin.html), pilih:

  • Nama printer default yang sama dengan di Windows.
  • Lebar kertas (58 mm atau 80 mm).
  • Template struk (simple / full) sesuai kebutuhan (receipt-print.html, receipt-print-full.html, dll).

3. Uji coba cetak

  1. Lakukan 1 transaksi percobaan di menu POS.
  2. Pastikan struk tercetak dengan rapi dan terbaca.
  3. Bila hasil terpotong atau berantakan, sesuaikan margin & pengaturan lebar kertas di aplikasi.
🧾

Jika printer tidak merespons sama sekali, pastikan driver sudah benar dan tidak ada antrian print error di Windows.

User, role & hak akses

Keamanan
Atur siapa saja yang boleh mengakses aplikasi dan menu mana yang dapat mereka gunakan.

1. Role yang umum digunakan

  • Owner / Superadmin – akses penuh termasuk pengaturan, master data, dan laporan.
  • Admin – hampir sama dengan owner tetapi bisa dibatasi di beberapa menu sensitif.
  • Kasir – fokus pada transaksi penjualan, tidak boleh mengubah harga pokok dan master data.

2. Membuat user baru

  1. Masuk sebagai owner/admin.
  2. Buka menu Pengguna / User Management.
  3. Klik Tambah User, lalu isi:
    • Username & password.
    • Role (Kasir / Admin / Owner).
    • Nama lengkap (opsional tapi disarankan).
  4. Simpan dan catat username untuk masing-masing pegawai.

3. Tips keamanan

  • Jangan berikan user admin/owner kepada kasir harian.
  • Gunakan password yang berbeda untuk setiap user.
  • Rutin ganti password bila ada pergantian pegawai.

Panduan cepat transaksi kasir (POS)

Kasir
Cara melakukan transaksi penjualan dari awal sampai cetak struk di menu POS (pos.html).

A. Langkah transaksi standar

  1. Login sebagai user kasir.
  2. Buka menu POS / Penjualan (pos.html).
  3. Cari barang dengan:
    • Scan barcode, atau
    • Ketik nama/kode lalu pilih dari daftar.
  4. Masukkan jumlah (qty) dan pastikan harga jual sudah benar.
  5. Pilih pelanggan bila penjualan tempo / piutang (opsional).
  6. Pilih metode bayar (tunai, transfer, dll).
  7. Klik Simpan / Bayar untuk menyelesaikan.
  8. Struk akan tercetak otomatis jika printer tersambung.

B. Shortcut penting untuk kasir

Simpan / bayar transaksi Enter
Cari barang CtrlF
Hapus baris barang Del
Batal transaksi Esc
💡

Latih kasir menggunakan shortcut di atas untuk mempercepat antrian di jam ramai.

Stok & mutasi barang

Stok
Mengatur keluar-masuk stok di luar transaksi penjualan biasa sehingga laporan stok tetap akurat.

Jenis mutasi yang umum

  • Stok masuk: pembelian dari supplier, stok awal, koreksi stok kurang.
  • Stok keluar: barang rusak, hilang, atau pemakaian internal.
  • Mutasi antar gudang (bila menggunakan multi-gudang).

Cara membuat mutasi stok

  1. Masuk menu Mutasi / Stok.
  2. Pilih jenis mutasi (masuk/keluar/pindah gudang).
  3. Pilih barang dan isi jumlah mutasi.
  4. Tulis catatan singkat (contoh: stok awal).
  5. Simpan dan cek apakah stok sudah berubah sesuai.

Piutang / hutang pelanggan

Piutang
Mengatur transaksi yang belum langsung lunas dan bukti cetak struk khusus piutang / pembayaran angsuran.

1. Mencatat piutang saat penjualan

  1. Pilih pelanggan yang sudah terdaftar.
  2. Pilih metode bayar tempo / piutang.
  3. Simpan transaksi.
  4. Aplikasi akan mencatat saldo piutang pelanggan tersebut.

2. Pembayaran piutang

  1. Masuk menu Piutang / Pembayaran di admin.
  2. Pilih pelanggan, lalu pilih transaksi/piutang yang akan dibayar.
  3. Isi nominal bayar dan metode pembayaran.
  4. Cetak bukti bayar bila diperlukan.
📌

Biasakan mencatat pembayaran piutang di hari yang sama saat pelanggan membayar, agar saldo selalu akurat.

Laporan penjualan & kas

Laporan
Mengakses ringkasan penjualan harian, bulanan, dan laporan kas lain untuk pemilik usaha.

1. Laporan penjualan

Biasanya tersedia di menu Laporan → Penjualan atau revenue.html.

  • Filter per tanggal / rentang tanggal.
  • Filter per kasir atau per shift (bila ada).
  • Cetak / ekspor (jika didukung) untuk arsip atau dilaporkan ke manajemen.

2. Cocokkan dengan kas fisik

  1. Ambil total penjualan tunai dari laporan.
  2. Cocokkan dengan uang di laci kas setelah dikurangi kas awal.
  3. Jika ada selisih, periksa:
    • Transaksi yang dibatalkan / dihapus.
    • Retur barang.
    • Salah input nominal bayar / kembalian.

Backup, restore & sinkron data

Backup
Menjaga keamanan data dengan rutinitas backup, serta pengenalan fitur sinkronisasi jika tersedia.

1. Backup rutin yang disarankan

  • Minimal 1x per hari setelah tutup toko.
  • Simpan file backup ke media eksternal (flashdisk / HDD eksternal) atau cloud.
  • Gunakan nama file yang jelas, misal: backup-pospro-2026-07-08.bak.

2. Cara backup

  1. Masuk sebagai owner/admin.
  2. Buka menu Backup Database di halaman admin.
  3. Pilih lokasi penyimpanan file backup.
  4. Tunggu sampai proses selesai dan catat lokasi file.

3. Restore (pemulihan) data

❗

Saat melakukan restore, data yang ada sekarang bisa tertimpa oleh data lama. Lakukan hanya bila benar-benar diperlukan.

  1. Pastikan file backup yang akan digunakan adalah versi terbaru yang Anda inginkan.
  2. Buka menu Restore Database dan pilih file backup.
  3. Ikuti instruksi di layar, kemudian restart aplikasi bila diminta.

4. Sinkronisasi data (bila fitur diaktifkan)

Beberapa instalasi POS PRO Offline dapat terhubung ke layanan sinkronisasi melalui halaman sync.html.

  • Gunakan hanya bila akun sinkron / server sudah disiapkan.
  • Pastikan koneksi internet stabil saat sinkron.
  • Hindari melakukan sinkron berulang kali saat jam sibuk, agar tidak mengganggu transaksi kasir.

Troubleshooting cepat

Bantuan
Daftar masalah yang paling sering terjadi dan solusi singkat yang bisa dicoba sendiri.

Masalah umum & solusi

Masalah Penyebab umum Solusi singkat
Aplikasi tidak bisa dibuka File terblokir antivirus / izin Windows. Jalankan sebagai admin, cek antivirus, atau reinstall.
Struk tidak tercetak Printer offline / salah pilih printer di aplikasi. Cek printer di Windows, lakukan test print, lalu cek lagi pengaturan printer di admin.
Selisih kas di laporan Ada transaksi dibatalkan, retur, atau salah input. Audit transaksi hari tersebut, cek log kasir (bila ada).
Stok tidak sesuai Mutasi manual tidak tercatat / penyesuaian stok belum dilakukan. Lakukan stok opname dan koreksi dengan mutasi stok.
🤝

Bila masalah belum terselesaikan setelah mengikuti langkah ini, siapkan screenshot error dan data singkat (kapan terjadi, di menu apa) sebelum menghubungi support, agar bantuan bisa lebih cepat.
